# POC 验收方案

目标是选定底座并识别适配工作。当前用例均为待执行，没有真实上游测试不能填通过。

## 实验设置

先测试 LiteLLM，关键能力失败再选一个备选。选一个内部 MaaS、一个自部署服务，必要时增加认证或协议明显不同的 MaaS；选两个真实客户端。使用合成 Prompt、隔离账号和受控预算，地址及凭证不进入公开记录。

固定网关、客户端、引擎、模型 revision、量化和模板。先直连建基线，再经网关运行同一用例；比较协议与路由，不要求随机文本逐字相同。

| ID | 操作 | 通过标准 |
| --- | --- | --- |
| T01 | 正常、过期认证和并发刷新 | 成败可定位，刷新不形成风暴 |
| T02 | SDK 普通与流式聊天 | 事件可解析，结束明确，无整段缓冲 |
| T03 | 两个并行工具及后续一轮工具 | ID、参数和工具结果保持关联 |
| T04 | 嵌套严格 JSON Schema | 独立校验通过或明确不支持 |
| T05 | 不支持参数与扩展参数 | 无静默删除，允许的扩展保留 |
| T06 | 固定部署与模拟故障 | 不静默切换，配置版本可查 |
| T07 | 429、5xx、连接和总超时 | 分类准确，重试有总预算 |
| T08 | 已输出后断流 | 标记不完整，不拼接其他模型 |
| T09 | 客户端取消 | 传播可测，不支持时记录残余资源 |
| T10 | 越权模型、透传和跨项目资源 | 一致拒绝，fallback 不绕过 |
| T11 | 长上下文、高并发 | 队列有界，其他项目受到保护 |
| T12 | 预算边界并发、失败和重试 | 预留结算可核对，未知用量单列 |
| T13 | 不同模板、量化和 LoRA | 目录可区分，严格模式不混用 |
| T14 | 文件或响应 ID 后续调用 | 原上游亲和，项目间隔离 |
| T15 | 正文采集、导出和过期删除 | 授权有效，导出无凭证 |
| T16 | 配置升级与回滚 | 生效版本可查，可重复回归 |
| T17 | 控制面或额度组件不可用 | 按设计处理，无未授权放行 |
| T18 | Embedding 或 Rerank | 维度、排序、批量和截断符合约定 |
| T19 | 数据库、配置与密钥材料恢复 | 隔离环境恢复后可验证模型与 Key，符合约定恢复目标 |
| T20 | 多副本条件项 | 跨副本撤销、并发和额度一致；单实例记 N/A |

不适用记 N/A 并说明理由。使用[结果表](../templates/poc-results.csv)记录版本、状态与脱敏证据。

## 性能方法

覆盖短输入短输出、长输入短输出、短输入长输出和工具调用；固定长度区间，逐档提升并发。冷热前缀缓存分组，报告样本数、错误率、P50/P95 首内容时间、总耗时、排队和吞吐。

网关开销用可控合成上游隔离测量。真实上游直连与网关交错测试，避免将模型波动归因于网关。报告网络位置、限流和缓存状态，不只给单个 RPS。

延迟目标、并发目标和预算超支容忍度须测试前确定，不用任意数字宣称成功。

## 决策输出

输出硬门槛、加权分数、适配工作、风险与回滚方案。保留首选及备选，填写[决策记录](../templates/decision-record.md)。
