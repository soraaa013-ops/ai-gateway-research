# 功能需求与优先级

P0 为首次共享试点前必需，P1 为扩大试点前补齐，P2 为需求明确后扩展。条件项在相关业务实际存在时进入 P0。

| ID | 功能 | 优先级 | 要求与验收 |
| --- | --- | --- | --- |
| F01 | 上游注册 | P0 | 区分 MaaS 与自部署；配置协议、地址引用、认证引用和模型映射；可停用单个部署 |
| F02 | 认证适配 | P0 | 覆盖真实 MaaS 认证；短期令牌可刷新且并发刷新受控；上游凭证不返回开发者 |
| F03 | 内部 Key | P0 | 归属用户或服务账号及项目，支持范围、有效期和撤销 |
| F04 | 模型授权 | P0 | 普通入口、原生透传、故障切换均执行授权 |
| F05 | 模型目录 | P0 | 记录模型与部署版本、能力、限制和验证日期；未验证不显示为支持 |
| F06 | 协议适配 | P0 | 覆盖真实客户端；保留流式事件、工具 ID、usage 和结束原因 |
| F07 | 严格调试 | P0 | 固定目标，默认无跨模型切换和答案缓存；参数变更可查 |
| F08 | 请求追踪 | P0 | 逻辑请求关联全部上游尝试；记录配置版本与错误来源 |
| F09 | 资源保护 | P0 | 项目和上游维度 RPM、TPM、并发、队列长度与等待期限 |
| F10 | 用量与额度 | P0 | MaaS 按平台口径，自部署按资源配额；未知 usage 不记为零 |
| F11 | 超时取消 | P0 | 区分连接、首事件、流空闲和总截止时间；取消尽可能传播 |
| F12 | 日志隔离 | P0 | 默认元数据；正文限时授权采集；项目隔离且有留存期 |
| F13 | 运维恢复 | P0 | 配置版本、校验、回滚；探活有频率和成本限制；变更审计 |
| F14 | 开发者入口 | P0 | 获取 Key、查看模型、复制接入示例、查询自己的失败请求 |
| F15 | 企业身份 | 条件 P0 | 公司要求统一登录时即接 SSO，否则采用可追踪的受控账号 |
| F16 | 高可用 | P1 | 多副本权限和额度一致；管理界面故障不阻断已授权请求 |
| F17 | 成本对账 | P1 | 区分平台账单、估算和内部核算；保存计价版本和修正记录 |
| F18 | 调试重放 | P1 | 脱敏后重新授权，生成新请求 ID，标记新调用和成本 |
| F19 | Mock 与故障注入 | P1 | 合成 429、超时和断流；与真实调用隔离 |
| F20 | 升级回归 | P1 | 网关、权重、模板、解析器升级后运行受影响用例 |
| F21 | Embedding 与 Rerank | 条件 P0 | 验证维度、批量、截断、归一化和输入限制 |
| F22 | 多模态与文件 | 条件 P0 | 验证上传、大小、资源归属、异步查询和取消 |
| F23 | 自动选模与语义缓存 | P2 | 具备评估集后启用，严格调试仍关闭 |
| F24 | MCP 与 Agent 治理 | P2 | 独立评审，不阻塞模型 API 服务 |

## 使用流程

进入项目 → 查看模型与协议 → 获取内部 Key → 复制示例 → 发起调用 → 用请求 ID 查询实际路由、耗时与失败原因。

管理员注册上游、验证能力、授权项目、设置限额，并在异常时停用或回滚配置。

## 公平性与预算

RPM 相同不代表负载相同。长上下文、大输出和高并发可能占满实例。初期用并发、输入长度、输出上限和有界队列组合；压测采用独立 Key 与资源池。

严格预算需要预留、结算及异常释放。成本上界依赖 tokenizer、计价和输出限制；无法可靠估计时声明软预算，并用并发与用量硬限额补充。不能仅靠调用结束后扣费宣称绝不超支。
